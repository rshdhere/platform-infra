# Platform infrastructure

Keep infrastructure for each project under its own directory. Shared GitHub automation lives in the root .github directory. For CMS changes, follow the project guide in cms/AGENTS.md.

Start with [.agents/context/architecture.md](.agents/context/architecture.md) for the repository map. Use the rules and workflows under .agents/ for the affected infrastructure. Run .agents/scripts/bootstrap.sh for local setup checks.
